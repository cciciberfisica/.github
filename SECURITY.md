# Política de Seguridad

El **Centro Colombiano para la Investigación Ciberfísica (CCIC)** prioriza la integridad numérica, la reproducibilidad y la seguridad de su software científico.

## Reporte de Vulnerabilidades

Si detectas una falla de seguridad, corrupción de memoria o anomalía crítica en cualquiera de nuestros repositorios:

1. **No abras un Issue público.**
2. Reporta el hallazgo de forma confidencial mediante la pestaña **Security / Advisories / Report a vulnerability** del repositorio correspondiente.
3. Incluye pasos mínimos para reproducir el problema, versión del compilador, sistema operativo y arquitectura.
